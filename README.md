# BBS And What It Is
BBS is a RTOS-based operating system, consisting of basic drivers and equipment.
It also includes commands like rm, grep, cat and mkdir.
# BBS and Why Should You Download It
 * BBS has amazing features including the BBUR Repository (Bold Based User Repository)
which helps BBS increase maximum consistency
 * BBS has withstanding embeddable and portability across everything, you can even boot up into a pentium
as of now, we have a small, embeddable kernel and a working init
# BBS Tools
